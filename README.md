# Winterlight

A 3D winter birthday card for Dhana, built phase by phase with Claude. Plain TypeScript, Three.js and Vite; everything (models, sound, effects) is generated in code.

```
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm test
npm run build
python3 tools/shot.py   # headless screenshots of dist/ (needs playwright)
```

Start with `CLAUDE_MUST_READ.md`. The plan is `PHASES.md`; the truth is `PHASE_STATUS.md`.
