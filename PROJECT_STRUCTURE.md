## Import boundaries (checked by `tests/boundaries.test.ts`, since Phase 2)
- `core/` imports nothing from `world/`, `character/`, `acts/`, `ui/`.
- `content/` and `state/` import nothing from `three`.
- `character/` imports `render/` and `core/` only.
- `acts/` may import everything below it; nothing imports `acts/` except `main.ts`.
- `ui/` talks to the scene only through the event bus.
- Pure logic (lock, quality tiers, constellation rules, state machines, blow detection, spring maths) lives in files with no `three` import so it is unit-testable.

## Naming
Phases are numbers. Files are camelCase. Acts are `actN_name`. Content keys are lowercase. Anything the owner edits lives in `content/` and nowhere else.
